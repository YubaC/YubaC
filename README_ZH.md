## 自述

自 2017 年以来，我和我的同僚们先后投身于单片机、无线电通信、Python、HTML、CSS 和 JavaScript 的研究或开发。一路走来，我们接触了许多不同的技术，也做过许多不同的事情。对于我而言，这始终是一场漫长而又有趣的探索。

最初吸引我的，或许只是技术本身。

我喜欢研究一个东西究竟是如何工作的，也喜欢亲手把一个想法变成能够真正运行的东西。从代码到电子设备，从一个小小的程序到完整的系统，我至今仍然享受这种从无到有的创造。

但后来我逐渐意识到，技术并不只是关于技术本身。

2022 年前后，我和我的同僚们开始了对于无障碍系统的探索。每个开发者开始接触无障碍系统的原因都是不同的，但我想我们大抵都有一个共同的地方，那就是我们希望自己所做的事情能够帮助一些人。

无障碍离我们并不远。事实上，它存在于你我日常生活的方方面面。

我至今仍常常回忆起第一次查看 W3C 组织编写的《Web 内容无障碍指南》时的那份深深的震撼。我似乎能够体会到那些文字背后所包含的爱和关怀，正如潮水般从字里行间向我涌来。

我不清楚编写这些文字的人当时究竟怀着怎样的心情，但我想，他们大概也曾希望自己所做的事情能够被某个人看见、使用，并最终帮助到另一个人。

于是我们便带着这份感触，投入到之后的工作中去了。

后来，我又逐渐接触到了自由软件、开放知识与数字保存。我开始发现，这些看似不同的事情之间，似乎存在着某种共同之处。

我们今天能够学习、使用和创造的东西，从来都不是凭空出现的。

我们来自社会，也依赖于无数人共同积累的知识、基础设施与劳动。我们能够站在今天的位置上，很大程度上正是因为有无数陌生的人在我们之前做过工作，并把他们创造的东西留给了后来的人。

我因此开始思考：那么，我们又能够留下些什么？

我没有找到一个最终的答案。

但至少，对于一个开发者而言，软件与技术是我能够用来回答这个问题的方法。

于是我开始尝试创造一些东西。

有时是一个软件，有时是一个工具，有时是一个电子设备；有时则只是整理、保存和记录一些本来可能被遗忘的东西。我也开始更加关心那些技术之外的问题：我们如何创造工具，如何使用工具，又如何让今天创造出来的东西能够被后来的人继续理解、使用和改进。

这些事情最终汇聚到了 LibYuba，以及我正在参与和创造的其他项目之中。

我仍然不知道这些探索最终会把我带到哪里。

我也仍然会改变自己的想法。今天认为重要的事情，未来未必仍然如此；今天没有答案的问题，也许多年以后依然没有答案。

但我想，我仍然会继续做下去。

就像那些曾经帮助过我的人一样，我希望能够把自己从这个世界中得到的一些东西，再传递给后来的人。

也许这就是我现在所能做的事情。

_— YubaC_
